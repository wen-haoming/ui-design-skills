# 高风险操作确认表单

## 使用与输入
用于资金、权限、删除或批量变更等有实质后果的操作，不给普通保存强加确认。先确定对象、范围、权限、可逆性、限制、费用及服务端状态；未知项不得编造。

## 执行与规则
1. 顶部显示动作与对象摘要；保留必要背景，避免用户确认错对象。
2. 将互斥方案做明确单选；只有选中方案需要的字段才展示。金额或数量旁说明上限、单位及约束。
3. 原因、备注与通知各自分组，区分必填与可选；有后果的通知开关写清接收对象，不预设替用户发送。
4. 在操作按钮附近呈现费用、不可恢复影响与预计处理情况；按钮写具体动作及关键数量，不用含糊“确定”。取消保持低风险。
5. 提交前校验权限、范围与最新限额；处理中防重复提交。超时显示结果未知并提供查询，不盲目重试；失败保留输入，成功显示结果凭据。

## 可访问性与验收
弹窗有标题、焦点约束和关闭后焦点恢复；字段有标签，错误关联字段并可被读屏识别。键盘可完成选择与取消，状态不只靠颜色。检查无效值、权限变化、重复点击与超时，确认不会误报成功。
