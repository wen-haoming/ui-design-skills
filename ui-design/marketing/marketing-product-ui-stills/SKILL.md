# 营销页中的产品界面静帧

## 使用与输入
用于落地页、功能介绍和 Bento 中的产品界面配图，不替代真实产品设计。先确定要强调的功能、画幅，以及哪些文字必须真实可读。不要把营销静帧里的示例数据写成产品现状。

## 执行与规则
1. 先搭完整界面结构，边缘用中性占位条；真实文字集中在核心区域，避免整屏假文案。具体数量按画幅和要强调的功能调整，不必机械固定字数。
2. 只设一个视觉主体，如窗口、卡片或设备框；让主体明显大于配角，并可沿一边裁出画外，不要四边等距悬浮。主体占比按实际画幅校准，不必机械套用固定比例。
3. 去掉闪光装饰图标和单字母方标等常见套模板符号。需要品牌时使用已有标识，没有就留空或用中性形状。
4. 完成后分别检查实际渲染宽度和窄屏预览（来源中的约 390px 只是可选参考）。按构图、层次、细节的顺序先改最严重的问题。

## 验收与边界
对照：能否一眼找到主体、边缘是否像未完成的界面结构、真实文字是否过载、主体是否居中漂浮。本方法只约束静帧。来源帖另提到录屏逐帧检查和安装命令，视频未审，也不把这些未实现能力包装进本技能。
