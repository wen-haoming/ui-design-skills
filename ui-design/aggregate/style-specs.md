# 首发三风格规格

本文件把三条首发风格写成可执行规格，供同一基准工作台使用。风格差异必须落在布局组织、字阶、密度、形态、对比和动效上，不能只换色，也不能改 `benchmark.json` 里的数据与功能。

Refero 在线风格库此前为无订阅状态，本规格不盲重试，也不伪造 Refero style ID。方向锁定来自已读的公开界面图、作者原文，以及 typography / color / motion / anti-slop 等工艺规则。

现有浅色 B2B 只占用其中一条（浅色精密工作台）。深色指挥台和浮动系统层不得再做成浅色后台换肤。

## `shallow-precise` 浅色精密工作台

- 布局：全幅产品壳，左窄导航，主区工具条+卡片内容；详情为右侧栏或主区切换，不做海报式悬浮。
- 字阶：标签 12/16 Medium，筛选 13/16、高度 28px，指标或标题 18/24 Semibold，正文字体 14–16。小字略加字距。单一无衬线。
- 密度：中等偏紧，对齐优先于装饰留白。
- 形态：筛选圆角约 6px，卡片约 14px；近黑实底主按钮；线性图标。
- 对比：画布近白，主文字近黑，边框浅灰。蓝只用于数据系列。绿/红只用于涨跌或对错。
- 动效建议：120–180ms，短位移或透明度。无弹跳、无扫光。
- 保留：量过的字阶和控件高、近黑主操作、细边框。
- 拒绝：默认紫个性色、厚投影营销卡、用浅字制造“透气”。

## `dark-command` 深色指挥台

- 布局：近黑壳+左侧导航；上为标题和指标，下为队列；或列表与详情对开。允许连续大圆角外壳，内容必须对齐。
- 字阶：页标题明显大于行标题，指标数字短而大，元数据更小但仍粗到可读。
- 密度：高于浅色精密，一屏同时看到范围、队列和上下文。
- 形态：大半径壳、中半径卡；选中行提亮；状态=文字+图标+底，不只靠色点。
- 对比：近白主文字，分割线低对比但可见。单一强调色且稀少。代码高亮色不得变成导航色。不要把常见默认紫写成签名。
- 动效建议：140–200ms。不使用霓虹描边或层层玻璃。
- 向 Wattenberger 只借：高密度可读正文、状态绿仅表示完成。
- 拒绝：靠另一套数据或假指标制造差异，发光卡片墙。

## `soft-system` 浮动系统层

- 布局：氛围底上的浮动窗口；左分组列表，右日志或详情；浮层是小面板；底部可有胶囊切换。不是全幅指标墙。
- 字阶：列表标题权重大，右侧保持可读正文行长；分组标题小而弱。
- 密度：外壳松、列表紧，像系统列表而不是卡片网格。
- 形态：连续大圆角窗口、胶囊工具、小状态符（环/勾/进度）。浅窗与深浮层共用这套形态。
- 对比：按当前层使用近黑或近白正文。状态先靠形状。确认或需处理可用小面积黄/橙。
- 动效建议：200–280ms 柔和显隐；氛围底缓慢且不抢内容。不把材质高光做成循环动画。
- 向 waylybaye 只借：胶囊工具条和大标题编辑层级，不宣称某品牌系统或 HDR 玻璃已实现。
- 拒绝：做成又一个浅色 B2B 仪表盘，或把氛围底画进内容区。

## 风格对照（同一基准下必须能看出来）

| 维度 | 浅色精密 | 深色指挥台 | 浮动系统层 |
|---|---|---|---|
| 壳 | 全幅近白后台 | 全幅近黑指挥壳 | 氛围底上的浮动窗 |
| 主结构 | 导航+工具条+卡片 | 导航+指标+队列/详情 | 分组列表+日志/详情 |
| 密度 | 中紧 | 高 | 外壳松、列表紧 |
| 主操作 | 近黑实底按钮 | 浅色文字按钮或少量实底，强调色极稀 | 胶囊或图标钮 |
| 状态 | 浅底标签 | 深底标签+图标 | 小形符号，颜色辅助 |
| 动效建议 | 短而克制 | 短而干脆 | 稍长、更软 |

若三份成品在缩略图里仍像同一套换色模板，即视为未完成。
