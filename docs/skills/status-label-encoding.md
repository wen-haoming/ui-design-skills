## SKILL 原文

# 状态标签的清晰编码

## 使用与输入
用于任务、审批、订单等需要快速扫读状态的列表、看板或筛选芯片。先列出真实状态、互斥关系、是否可点击或筛选，以及必须同时支持色觉差异与灰度查看。不要为装饰增加无业务含义的标签。

## 执行与规则
1. 每个状态同时给出简短名称、可区分图标和浅底色；名称用业务用语，不用单靠色点。
2. 同一组标签保持相近高度、内边距和图标位置，方便成行扫描。进行中、待处理、已完成、已取消等对立状态，图标结构也要明显不同。
3. 未开始或空状态可用虚线或低对比样式，但文字仍需可读；不要做成“看不见的占位”。
4. 若标签可筛选或可点击，选中态要有文字或描边，不只加深底色。不可用的状态保持可辨认，并在交互上禁用。

## 可访问性与验收
颜色对比满足正文或大号文本要求，图标配有名称或等效文本。检查色盲模拟、灰度、深浅主题、长翻译词和缩小点击区。对照默认、选中、禁用和成组排列，确认不会把不同状态看成同一种。
