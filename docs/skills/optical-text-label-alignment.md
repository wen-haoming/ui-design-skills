## SKILL 原文

# 紧凑界面文字与标签光学对齐

## 使用与输入
用于列表、数据行、状态标签与说明混排时的细节校准；不替代整体布局设计。输入真实字体、字号、图标、长短文案、交互状态及对齐目标。先区分要对齐文字、图标还是数值，不机械统一所有边缘。

## 执行与规则
1. 隐去装饰底色检查阅读顺序，为同一语义列确定文字起点或基线。正文、标签和辅助说明先按文字建立锚点。
2. 带背景标签若因内边距显得缩进，让装饰背景向列外延伸，文字仍与相邻内容对齐；不要为对齐容器而让文字错列。
3. 保留内部间距和真实点击区；优先以包裹层分离装饰与布局，避免负边距压住邻项、造成裁切或重叠。
4. 数值列按比较任务选择右对齐等方式，图标按视觉中心微调；这些是扩展建议，不是参考图已证明的规范。

## 状态、可访问性与验收
分别检查默认、选中、悬停、聚焦、禁用和换行。装饰不可遮焦点环，标签内容保持可读；缩窄、文字放大、中文、不同字体及双向文字下不截字。验收时对比有无底色两种视图：阅读列稳定、间距一致、点击区不重叠，且无横向溢出。调整值通过实图校准，不虚构原作像素参数。
