# 把文字排好，比再加一种颜色更要紧

做界面时，人们常先选颜色和组件，把段落、标题和引用留到最后才填进去。结果常常是：字号层级含糊，一行拉得过长，中英文挤在一起，读者还没看清意思，眼睛先累了。排版不是装饰，而是让文字按顺序被读完的路径。

## 先让眼睛找到路径

一篇讲得清楚的界面文稿，通常只需要很少的层次：先看到标题，再看见小标题，然后才进入段落、列表和引用。层次一乱，所有句子都会争抢同一视线。排的时候可以先问三件事：

- 标题和正文的对比是否足够，不必靠变色取胜
- 一段话是否停在舒适的行长里，而不是顺着屏幕一直铺过去
- 列表、引用和普通段落会不会看起来像同一种灰块

这三件事做对了，版面即使颜色很少，也仍然站得住。

## 中文、英文和数字要一起过日子

中文排版还会碰到夹排。例如在句子里写到 CSS 的 line-height: 1.75 时，英文单词和数字不应在中间被切断，标点也不该孤零零跑到行首。中文句子的停顿靠的是完整的句读，而不是把符号随便折到下一行。

> 把字距、行高和行长看成一套呼吸，而不是三个互不相干的旋钮。少调一点，让段落自己把气口留下来。

引用的作用是换一种口气，而不是把同一句话再加大加粗一遍。链接也应当能被认出来，并且在只显示文字时仍然说得清自己指向哪里。

## 同一篇文章，也可以换一种呼吸

同一份文稿可以读得慢，也可以被快速扫过。长文阅读需要更从容的行距和行长；杂志式编排可以用更大的标题对比来打开章节；紧凑的知识笔记则把列表和要点收得更近，方便对照。无论哪一种，内容应保持原样：不增删句子，不把文章拆成待办任务，也不用版式变化冒充新的事实。

好看的文字排版，不是再发明一套炫技样式，而是让已写好的句子，在不同阅读目的下都能被诚实地读完。
