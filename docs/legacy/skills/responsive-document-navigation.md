# 响应式长文档导航

## 使用与输入
用于多章节帮助中心、知识库或技术文档；短文章不强加三栏。输入章节树、正文标题、主要设备、固定栏和已有导航能力。

## 执行与规则
1. 桌面分离全局章节、正文和页内目录；根据可用宽度逐级收起侧栏，断点按内容拥挤程度确定，不照搬固定数值。
2. 窄屏用明确入口展开章节列表，一行一项；可采用底部入口与全屏面板。关闭后保持正文位置，当前章节有文字或结构标识。
3. 长导航独立滚动，溢出边缘可用渐变和按钮提示；不能遮住末项或成为唯一提示。定位标题时考虑吸顶栏，链接支持直接访问。
4. 仅存在级联菜单时使用方向安全区：鼠标朝子菜单移动时暂缓误触其他行；移出或等待上限到达才切换。触屏改为点击，键盘不受悬停计时限制。

## 状态与验收
面板打开时管理焦点，关闭后归还入口；章节树使用语义化链接和展开按钮，勿给普通站点导航滥用菜单角色。检查长标题、放大、窄屏、深层链接和空章节；级联还测斜向移动、边缘翻转、Esc及方向键。
