# 运营指挥中心的信息层次

## 使用与输入
用于库存、审批、仓储或类似需要监视与处理并行的后台首页。先确定监控范围、刷新时间、最重要的异常，以及每个卡片要导向的下一步。没有真实数据时标明示例，不把参考图里的指标当用户数据。

## 执行与规则
1. 先固定范围：导航分组、当前场所或对象、更新时间和全局搜索；主操作与范围信息放在页头，避免和卡片抢位置。
2. 首屏按任务分区：概览指标、一条主导趋势、需要处理的列表、结构或构成说明。不要把所有图表做成同等大小的装饰块。
3. 指标卡写清名称、当前值、对比或阈值，以及进入明细的入口。异常数量应可指向具体列表，不能只显示涨跌百分比。
4. 图表和构成图需有图例或分类名称；状态用文字加颜色，不以单色块代替说明。

## 可访问性与验收
卡片标题和数值可被辅助技术按顺序读出；图表不只靠色带区分。检查数据为空、部分失败、范围切换和窄屏：次要图可降级，待办和异常入口仍在。本方法只覆盖静态层次，不声称已验证悬停、实时刷新或拖拽。
